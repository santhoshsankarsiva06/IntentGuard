# IntentGuard — offline intent mismatch prototype

Target: Windows on a Snapdragon-powered HP PC. The prototype processes pasted English, Tamil, or Thanglish messages and URLs or uploaded QR images locally. It predicts the message's intent with a **scikit-learn** character n-gram CountVectorizer + MultinomialNB model, then applies explicit URL/UPI mismatch rules. The trained model is bundled as `intent_model.joblib` and runs without a cloud API.

## Run in VS Code on Windows

1. Extract the ZIP (do not run code inside the ZIP preview).
2. Open VS Code. Choose **File > Open Folder** and select the inner `IntentGuard_Submission_Ready` folder containing `app.py` and `requirements.txt`.
3. Choose **Terminal > New Terminal**. If the terminal prompt begins with `PS`, type `cmd` and press Enter to switch this terminal to Command Prompt. The prompt should end in `IntentGuard_Submission_Ready>`.
4. Run these commands **one at a time** in that VS Code terminal:

```cmd
C:\Users\sivae\.venv\Scripts\python.exe -m pip install -r requirements.txt
C:\Users\sivae\.venv\Scripts\python.exe app.py
```

If the previous virtual environment is missing, run `py -m venv .venv` inside this folder. Then replace `C:\Users\sivae\.venv\Scripts\python.exe` in both commands above with `.venv\Scripts\python.exe`. Activation is not necessary. If VS Code prompts for an interpreter, choose **Python: Select Interpreter** and select the same `python.exe`; this is useful for editing and Run buttons, but the terminal commands already specify it.

The first command downloads packages during setup and may take several minutes. Inference works offline afterward. Do not run model files downloaded from strangers: joblib loading trusts the bundled file.

## Demo cases

Use the target `upi://pay?pa=example@upi&am=500` in each test. Click Analyze.

| Message | Expected model intent | Expected verdict |
| --- | --- | --- |
| Your scholarship is ready. Scan this QR to receive it. | receive money or benefit | Suspicious mismatch |
| உங்கள் கல்வி உதவித்தொகை தயார். பெற இந்த QR-ஐ ஸ்கேன் செய்யுங்கள். | receive money or benefit | Suspicious mismatch |
| Ungal scholarship amount ready. Pera intha QR scan pannunga. | receive money or benefit | Suspicious mismatch |
| Please pay the workshop fee. | make a payment | No mismatch found (not a safety guarantee) |

The explanation is generated by rules comparing the predicted intent and parsed target; the classifier does not explain its own internal weights. The dataset has only 144 illustrative examples, and these demonstrations are smoke tests, not measured accuracy. To retrain with your own examples, edit `DATA` in `train_model.py`, run `python train_model.py`, and restart the app.

## Competition rule mapping

- **Hardware target:** Designed as a Windows desktop workflow for Snapdragon-powered HP PCs. The small offline classifier is intended to run on CPU. Validate Python/NumPy/OpenCV/scikit-learn installation on a Windows ARM64 HP PC and record a timed demo before claiming verified native performance. There is currently no Snapdragon NPU acceleration or Qualcomm AI Hub integration; those are future optimizations, not implemented features.
- **AI model:** The bundled machine learning pipeline is trained and run using the open-source [scikit-learn platform](https://scikit-learn.org/) (BSD-3-Clause). It is a classical classifier, not a transformer or Qualcomm AI Hub model. If the organizer means a pretrained open-source model rather than a model built with an open-source platform, ask them to clarify or integrate such a model before submitting.
- **Individual entry:** Submit the proposal on Unstop yourself as a solo participant. The app cannot perform registration or submission.

This is a prototype, not a certified scam detector. It does not open links, resolve redirects, check URL reputation, verify payees, or prove a site is safe. Inference is offline, but installation may require internet access.
